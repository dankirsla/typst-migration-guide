# Typst for Academic Researchers: A Practical Migration Guide

A practical guide to migrating academic documents from LaTeX and Word to [Typst](https://typst.app/).

This guide covers the main concepts and workflows researchers need when moving to Typst, including:

* Installing Typst and creating a project
* Basic Typst syntax and document structure
* Mathematical notation and equations
* Figures, tables, labels, and cross-references
* Citations and bibliographies
* Scripting, variables, functions, and multi-file projects
* Templates and journal-specific formatting
* Organizing a migration from LaTeX or Word
* Common limitations and migration considerations

The guide is intended for academic researchers who are considering Typst as an alternative to traditional LaTeX or Word-based workflows. It focuses on practical migration rather than providing a complete reference to the Typst language.

## Documentation basis

This guide was prepared from publicly available Typst documentation and related project resources. It is a researched technical guide rather than a record of independent testing.

Because Typst is actively developed, commands, package behavior, templates, and other details may change between versions. Always check the current Typst documentation and the requirements of the target journal before applying the procedures described here.
